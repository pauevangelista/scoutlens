# Analysis

`spearman.py` checks how well the app's criterion scores rank photos the way scouts do, overall and within each disclosed group.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python spearman.py fixtures/synthetic_ratings.csv
python spearman.py ratings.csv --group-cols gender age_band --min-n 10 --out results.csv
```

## Input CSV

One row per photo per scout.

| Column | Meaning |
|---|---|
| `photo_id` | Photo identifier. Pseudonymous, never a name. |
| `scout_id` | Scout identifier. |
| `gender`, `age_band` | Disclosed group columns (change with `--group-cols`). Blank means not disclosed. |
| `app_<id>` | The app's 0 to 100 score for criterion `<id>` from `rubric.json`. The same on every row of a photo. Blank if not measured. |
| `scout_<id>` | That scout's rating for the same criterion. Any ordinal scale works, since Spearman uses ranks. |

Criterion ids are read from `../rubric.json`. Columns for ids not in the rubric are ignored with a warning, and a criterion needs both its `app_` and `scout_` column.

## What it reports

For each criterion, Spearman's rho between the app score and the mean scout rating per photo, with the p-value and number of photos:

- for all photos, and
- within each level of each group column, with blanks reported as "not disclosed".

Rows with fewer than `--min-n` photos (default 10) are marked "too few to interpret". Group columns only split the report; they are never used to compute any score.

A lower rho in one group means the app ranks that group's photos less like the scouts do, which is the signal to look into. Comparing rhos between groups formally (for example a Fisher z test) is not done here yet.

## Data rules

Only synthetic data is committed. `fixtures/synthetic_ratings.csv` is generated by `make_fixture.py` with a fixed seed. It includes a deliberate group difference (ratings for one group follow the app score less closely) so the split is visible in the report. Real study data stays in university-approved storage and is never committed.
