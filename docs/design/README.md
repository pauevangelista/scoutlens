# ScoutLens design

Design for the first-run onboarding and results screens (12 phone screens).

- Live design canvas (private to the author): https://claude.ai/artifact/N8vmiw3AWXMi4TjFYmNbam
- `canvas/` holds the source files of that canvas. They are Design Component pages and need the canvas to render, so treat them as reference, not as app code.
- `design-system.md`: colors, type, radii, components, copy and accessibility rules.
- `onboarding-flow.md`: the screens, what each collects and how each answer is used.
- `photo-shot-list.md`: the photos to shoot for the placeholders (P1 to P6) and the release rules.
- `claude-md-addition.md`: design rules to append to the project CLAUDE.md.
- `implement-design.prompt.md`: the prompt to paste into Claude Code to build this in the Expo app.
