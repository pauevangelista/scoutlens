# Photo shot list

Placeholders in the design are labelled with these codes.

| Code | Photo | Where it goes | Color |
|---|---|---|---|
| P1 | Portrait, window light, plain wall, natural expression | Welcome hero | B&W allowed |
| P2 | Three digitals of one person (face close-up, full length, side profile), done properly | "What good looks like" | Color, unretouched |
| P3 | Plain wall next to a busy background | Guide: choosing a wall | Color |
| P4a / P4b | Same outfit and wall: window behind vs window in front | Notes: Bright spots | Color |
| P5 | Feet cropped vs full length with space around | Guide: framing | Color |
| P6 | A friend holding the phone at chest height, candid | Guide and photos screen | B&W allowed |

## Rules
- Written model release from everyone shown, and a written licence from each photographer (app, thesis, store screenshots).
- Adults only. A range of skin tones, ages, bodies and genders.
- Shoot digitals with a phone, as users will.
- No retouching on example digitals.
- In "not yet" photos the problem must be technical (light, background), never about the person. Get the person's agreement to appear.
- No stock, celebrity or agency photos without a licence.
